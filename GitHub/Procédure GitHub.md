# Workflow Git

## Avant de commencer

```powershell
git pull
```

Récupère les dernières modifications du dépôt.

---

## Après avoir modifié la documentation



### Vérifier les modifications

```powershell
git status
```

### Ajouter tous les fichiers

```powershell
git add .
```

### Créer un commit (Une sauvegarde du projet)

```powershell
git commit -m "Description des modifications"
```

Exemples :

```powershell
git commit -m "Add Docker documentation"
```

```powershell
git commit -m "Update PowerShell cheat sheet"
```

### Envoyer sur GitHub (Tous les commit)

```powershell
git push
```

---

## Vérifier l'historique

```powershell
git log --oneline
```

---

## Télécharger les dernières modifications

```powershell
git pull
```
